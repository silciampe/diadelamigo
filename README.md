# Nosotras ❤️

Proyecto interactivo realizado como regalo para el Día del Amigo.

La experiencia consiste en un recorrido emocional donde cada amiga descubre una dedicatoria escrita especialmente para ella.

El objetivo no es crear un juego, sino una experiencia cálida, elegante y emotiva.

---

## Concepto

Las personas aparecen representadas únicamente por sus fotografías.

Al hacer clic sobre una foto:

- la fotografía cobra protagonismo
- el resto se desvanece
- se abre una carta
- aparece una dedicatoria escrita especialmente para esa persona
- el texto se revela lentamente

Cuando todas las cartas fueron descubiertas:

- aparece la carta final (Sil)
- luego todas las fotografías se unen formando una única imagen del grupo
- aparece el mensaje final del Día del Amigo

---

## Estilo

Minimalista.

Elegante.

Mucho espacio en blanco.

Animaciones suaves.

Nada debe sentirse como una aplicación.
Debe sentirse como abrir un álbum de recuerdos.

---

## Paleta

Fondos claros.

Tipografía elegante.

Mucho aire.

Detalles en tonos cálidos.

---

## Sensación

La experiencia debe transmitir:

- amistad
- cariño
- nostalgia
- cercanía
- gratitud
- alegría

Nunca debe sentirse infantil.

Nunca debe sentirse recargada.

Todo debe ser delicado.
