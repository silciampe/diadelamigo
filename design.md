# Diseño

El sitio NO debe parecer una aplicación.

Debe parecer una experiencia.

Inspiraciones:

- Apple
- Notion
- Linear
- Framer

Mucho espacio.

Nada de botones enormes.

Nada de colores fuertes.

Nada de sombras exageradas.

Animaciones lentas.

Transiciones de aproximadamente 500 ms.

El usuario debe sentir tranquilidad.

Cada pantalla debe tener un único foco visual.

Usar tipografía elegante.

No abusar de iconos.

Todo debe respirar.
